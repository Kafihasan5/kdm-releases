# Quantum Download Manager

Downloads over every connection you have at once, with YouTube and a Chrome extension.

## Windows

Download [QuantumDM-Setup-x64.exe](https://github.com/Kafihasan5/kdm-releases/releases/latest/download/QuantumDM-Setup-x64.exe) and run it. If SmartScreen appears, choose **More info**, then **Run anyway**.

## Mac

Paste this into Terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/Kafihasan5/kdm-releases/main/install.sh | sh
```

Or use a disk image: [Apple Silicon](https://github.com/Kafihasan5/kdm-releases/releases/latest/download/QuantumDM-mac-arm64.dmg) or [Intel](https://github.com/Kafihasan5/kdm-releases/releases/latest/download/QuantumDM-mac-intel.dmg).

1. Open it and drag the app to Applications.
2. Open the app. macOS says it can't check it, because the app isn't signed by an Apple developer.
3. Open **System Settings → Privacy & Security**, scroll down and press **Open Anyway**.

The app updates itself after that.
